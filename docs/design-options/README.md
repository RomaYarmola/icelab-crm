## Що це означає для плану B3

- Рішення про логотип і колір (раніше «тимчасова іконка IL») закрито: логотип з `assets/`, кольори зі списку вище.
- Для PWA: колір рядка стану і тло запуску `#FFFFFF`, значок із `mark.svg`.
- Запиту логотипа в Романа більше немає.

## Як перезібрати картинки і PDF

Потрібен лише Google Chrome (нічого встановлювати не треба). З папки `docs/design-options`:

```bash
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$CHROME" --headless=new --hide-scrollbars --allow-file-access-from-files --force-device-scale-factor=2 --screenshot="$PWD/04-variant-C-minimalistychnyi.png" --window-size=1500,1180 "file://$PWD/design-options.html?sheet=c"
```

Параметр `sheet` приймає `o` (порівняння), `a`, `b`, `c`. Для PDF: `--print-to-pdf=...` з адресою `design-options.html?sheet=all` і прапорцем `--no-pdf-header-footer`.
