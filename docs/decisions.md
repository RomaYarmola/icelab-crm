## Рішення, прийняті під час створення каркаса

| Рішення | Причина |
|---|---|
| Turbopack за замовчуванням | У Next.js 16 Turbopack стабільний і для `dev`, і для `build`, тому скрипти без прапорців. У блоці B3 для PWA може знадобитися `next build --webpack`: Serwist офіційно не підтримує Turbopack |
| ESLint flat config без FlatCompat | `eslint-config-next` 16 несумісний із `FlatCompat` (помилка «circular structure»), тому конфіг підключає його вбудовані flat-експорти. Пакет `@eslint/eslintrc` прибрано |
| `AGENTS.md` у корені | Його створює `next dev` (правила для AI-агентів зі вказівкою на документацію версії Next). Лишаємо в репозиторії; вимкнути можна опцією `agentRules: false` у `next.config.ts` |
| Без Google Fonts | Системні шрифти: не залежимо від зовнішнього CDN під час збірки і для офлайн-режиму PWA |
| Без темної теми | ТЗ: «темная тема не требуется» |
| Змінні середовища перевіряються ліниво | `next build` у CI не має реальних секретів |
| Підключення до БД: `max: 1`, `prepare: false`, `ssl: require` | Сумісно з пулером Supabase і з serverless-функціями Vercel |
| Пакети Supabase (`supabase-js`, `ssr`) додаємо в B2 | У B0 вони не потрібні |
