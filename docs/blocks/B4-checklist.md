# B4. Чек-лист ручної перевірки

Для кроків 5.2 і 5.3 з [плану блока](B4-clients.md). Тестові користувачі (по одному на роль) уже є на `icelab-dev`, паролі лежать у файлі `.dev-users.local` у корені проєкту (у репозиторій не потрапляє). Адреса: `https://icelab-crm.vercel.app` (Production) або прев'ю PR 2.

Відмічайте `[x]`, що пройшло. Якщо щось не так, напишіть, на якому кроці і що побачили.

## 0. Підготовка

Клієнтів у базі ще немає, тож для перевірки Claude додає вигаданих (усі з назвою «Тест: …»). База одна з Production, тому це робиться лише після вашого «так»:

```bash
npm run clients:seed-dev
```

- Додає 15 клієнтів: Київ (АА), Київська область (АІ), Львівська (ВС), Тернопільська (ВО) і один без області (код з цифр). Серед них навмисний дубль «Кафе «Вогнік» (дубль)» з тим самим телефоном, що й у «Кафе «Вогник»».
- `npm run clients:seed-dev -- --bulk` додає ще 35 клієнтів, щоб перевірити «Показати ще» (список показує по 30).
- `npm run clients:seed-dev -- --remove` видаляє всіх «Тест: …» з контактами, адресами й цінами.

- [ ] Власник увійшов і бачить у «Клієнтах» тестових клієнтів

## 1. Список і пошук (телефон і комп'ютер)

- [ ] «Клієнти»: зверху «Новий клієнт», рядок пошуку, «Фільтри», далі картки (код справа, назва, статус і менеджер, телефон)
- [ ] Пошук за назвою: «вогник» знаходить обидва «Вогник» і «Вогнік»
- [ ] Пошук з помилкою в літері: «Вогнік» (з «і» замість «и») усе одно знаходить «Вогник»
- [ ] Пошук за кодом: «АА15», «аа15» і латинськими літерами «AA15» дають один результат (код підставте з вашого списку)
- [ ] Пошук лише цифрами «21» знаходить клієнта без області
- [ ] Пошук за телефоном: «111 22 33» або «0501112233» знаходить «Вогник»
- [ ] Пошук за ім'ям контакту: «Петренко»
- [ ] Поки ви друкуєте, список не стрибає: він оновлюється, коли ви зробили паузу, у полі з'являється індикатор
- [ ] Хрестик у полі очищає пошук
- [ ] Адреса сторінки містить пошук (`?q=…`). Надішліть її собі, відкрийте: пошук той самий. «Назад» повертає до попереднього стану
- [ ] Фільтри: статус, менеджер, застосування; кількість увімкнених видно в «Фільтри · 2»
- [ ] «Нічого не знайдено» з підказкою, коли нікого немає
- [ ] З `--bulk`: під 30 клієнтами кнопка «Показати ще» додає наступні, без повторів

## 2. Новий клієнт

- [ ] «Новий клієнт»: області від «АА · Київ» до «ВО · Тернопільська область» і «Без області (код з цифр)»
- [ ] Під полем області видно «Код клієнта буде АА16…», підказка змінюється з областю
- [ ] Створіть клієнта з областю Києва, потім Львова (ВС) і без області: коди «АА…», «ВС…» і число
- [ ] Телефон можна вводити як звичайно (`050 123 45 67`); коли вийшли з поля, він стає «+38 050 123 45 67»
- [ ] Введіть назву «Кафе Вогник» і перейдіть до наступного поля: з'являється «Схожі клієнти» з посиланням, збереження не заблоковано
- [ ] Введіть телефон «050 111 22 33»: теж видно схожого клієнта (той самий телефон)
- [ ] Після створення відкривається картка з повідомленням «Клієнта створено. Його код: …»
- [ ] Порожня назва: зрозуміла помилка, введене лишається

## 3. Картка клієнта

- [ ] Вгорі назва, код, статус і менеджер; вкладки «Основне», «Контакти», «Адреси», «Ціни» вміщаються в один рядок (на 360 px теж)
- [ ] Вкладка в адресі (`?tab=contacts`): посилання відкриває потрібну вкладку. «Назад» веде до списку клієнтів, а не перебирає вкладки
- [ ] «Основне»: змініть назву, статус, менеджера, примітку, збережіть: «Зміни збережено.»
- [ ] «Додатково»: тип льоду, тара, ЄДРПОУ (8 або 10 цифр), окрема надбавка, нагадування
- [ ] Клієнт без області: є «Додати область до коду», після вибору код змінюється, старий код у примітці
- [ ] «Контакти»: додайте контакт, змініть, зробіть основним (основний лише один), видаліть (двома натисненнями). Натисніть на телефон: на телефоні відкривається набір номера
- [ ] «Адреси»: додайте доставку, склад Нової Пошти (з'являється поле «Номер відділення»), автобус; «За замовчуванням» лише одна
- [ ] Некоректний телефон дає зрозумілу помилку, а не збій

## 4. Ціни клієнта і «Прайс»

- [ ] Власник: «Ще → Прайс». Для кожного типу льоду внесіть ціну («Нова ціна від дати», наприклад 75 ₴/кг із сьогоднішньою датою)
- [ ] Змініть ту саму ціну з дати «завтра»: у картці видно «З … : нова ціна», а стара ще діє
- [ ] «Історія цін» показує період кожної ціни: закриту, чинну і майбутню
- [ ] Картка клієнта, «Ціни»: для типів без своєї ціни написано «За прайсом» і ціну з прайсу
- [ ] Менеджер: «Нова ціна від дати» для клієнта (окремо на тип і «для будь-якого типу»). Поряд видно «У прайсі: …»
- [ ] Така сама ціна, що вже діє, не приймається (повідомлення), ціна 0, від'ємна чи текст теж
- [ ] Менеджер у «Прайс» лише дивиться: форми зміни немає, є підказка «Прайс змінює власник»

## 5. Видалення і об'єднання (лише власник)

- [ ] Картка «Тест: Склад №4»: «Видалити клієнта» розкриває підтвердження. Після підтвердження клієнт зникає зі списку
- [ ] «Фільтри → Показати видалених»: видалений клієнт є, на його картці «Повернути до списку», після чого він знову в списку
- [ ] Картка «Кафе «Вогник»»: «Об'єднати з дублем», у пошуку знайдіть «Вогнік (дубль)», оберіть
- [ ] Підсумок: скільки контактів, адрес і типів льоду перейде; для ціни на 16 мм написано, що ціна дубля лишається в дубля (в головного вже є своя)
- [ ] «Поміняти місцями» міняє, хто головний
- [ ] Підтвердіть: відкривається картка головного, є «Клієнтів об'єднано», контакти й адреси з дубля на місці, в примітці рядок «Об'єднано з …»
- [ ] Дубля у списку немає. З «Показати видалених» він є, на його картці написано, що його об'єднано
- [ ] Менеджер не бачить «Видалити» й «Об'єднати з дублем», а адреса `…/merge` повертає його на картку

## 6. Права за ролями

Увійдіть кожною роллю й перевірте:

| Роль | Клієнти | Новий клієнт і зміни | Вкладка «Ціни» | «Ще → Прайс» |
|---|---|---|---|---|
| Власник | так | так | так, змінює | так, змінює |
| Менеджер | так | так | так, змінює | так, лише дивиться |
| Старший локації | так | ні, лише перегляд | немає | немає |
| Виробництво | розділу немає | розділу немає | розділу немає | немає |
| Бухгалтер | так | ні, лише перегляд | так, лише дивиться | так, лише дивиться |

- [ ] Власник
- [ ] Менеджер
- [ ] Старший локації: на картці немає вкладки «Ціни», у списку немає цін, `…/clients/new` повертає до списку
- [ ] Виробництво: адреса `/clients` перекидає на «Виробництво»
- [ ] Бухгалтер: усе лише для перегляду, форм зміни немає

## 7. Вигляд

- [ ] На телефоні 360–430 px немає горизонтальної прокрутки, шрифт не дрібніший за 16 px, кнопки й поля зручно натискати
- [ ] Екранна клавіатура не перекриває поле телефону й кнопку «Зберегти» (екран прокручується)
- [ ] На екрані від 1024 px список у дві колонки, форми не розтягнуті на весь екран
- [ ] Каталог `/ui-kit` (на локальному сервері) показує нові компоненти: пошук, вкладки, розкривний блок, чекбокс, телефон
