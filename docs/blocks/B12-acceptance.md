# Приймання блока «Водій» (B12)

Складено 23.11.2026 за [ТЗ](../IceLab-CRM-TZ-rozrobnyk.pdf), розділи 2.1, 4.6, 5.1, 6.13, 8.2 і 13 (етап 3, «Кнопка для водія»). План: [B12-driver.md](B12-driver.md). Блок **прийнятим не оголошуємо**: справжньої доставки з водієм ще не було, усе перевірено на підмінених відповідях Telegram.

## Критерій ТЗ §13

«Водій у боті бачить замовлення дня своєї локації зі способом "доставка", відмічає "Доставив" і вводить готівку; статус "відправлено" і сума видні в системі.»

| Що | Чим перевірено | Стан |
|---|---|---|
| `/today` показує доставки сьогодні своєї локації, без самовивозу й чужих дат | `tests/server/driver.test.ts` («перелік», «чужа локація») | Закрито автотестом |
| Картка без цін, з телефоном, картою й «готівка: очікується» | `driver.test.ts` («перелік», `driverCardText`) | Закрито автотестом |
| «Доставив»: Запаковано → Відправлено; повтор нічого не змінює; ще не запаковане відхиляється | `driver.test.ts` («Доставив», бот: повтор) | Закрито автотестом |
| Готівка: «450 грн», помилки вводу (не число, нуль, від'ємне, понад залишок, порожнє), `driver_bot`, повна сума оплачує й закриває | `driver.test.ts` («готівка», бот: діалог до кінця) | Закрито автотестом |
| Діалог зберігається між повідомленнями, застарілий не діє | `driver.test.ts` («діалоги») | Закрито автотестом |
| Не водій і чужий Telegram не мають доступу | `driver.test.ts` («відмова», «денай») | Закрито автотестом |
| Таблиця `telegram_sessions` і запити на справжньому Postgres | Відкатна транзакція на dev: міграція, запис, читання, очищення, список доставок | Перевірено 23.11.2026. **Міграцію на dev не застосовано** |
| Водії в списку підключення Telegram | `telegram-admin.test.ts` | Закрито автотестом |

Перевірки коду: lint, типи, формат, усі тести (1550).

## Водії з виробництва (D241, D243, 26.11.2026)

Роль «Водій» окремо не заводимо: ті самі команди мають «Виробництво» й «Старший локації». Закрито автотестом (`driver.test.ts`); **чекає перевірки в справжньому боті:** власник підключає людині Telegram («Прийом заявок»), вона пише `/today`, відмічає «Доставив», вносить готівку.
